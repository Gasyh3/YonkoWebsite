===========================================

Mode d'emploi
-------------
- Écrivez votre texte après chaque flèche « → ». Laissez vide si le texte proposé vous convient
  (écrivez alors « OK »).
- « Actuel : » = le texte provisoire affiché aujourd'hui sur le site, marqué [à adapter] ou
  [à remplacer] dans le code. Rien de ce qui est marqué ainsi n'est définitif.
- Les longueurs indiquées (en caractères, espaces compris) correspondent à la place prévue
  dans la mise en page. Les dépasser peut casser l'équilibre d'une section.
- Pour le référencement : un titre de page fait au plus 60 caractères, une description entre
  140 et 160 caractères, avec le métier et la ville quand c'est pertinent.
- Renvoyez ce fichier rempli tel quel : chaque bloc correspond à un endroit précis du site.
