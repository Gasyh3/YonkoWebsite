YONKO TECH CONSULTING : CONTENUS
================================

Tous les textes du site sont rédigés (questionnaire d'octobre 2026). Principes retenus :
- Agence web basée à Antananarivo, travail à distance partout, depuis 2025.
- « Nous » pour l'agence, un seul interlocuteur ; pas de promesse intenable (aucune position
  Google garantie, aucun délai chiffré), aucune statistique inventée.
- Les offres v1 (ERP, SaaS, SEO & rebranding, réseaux sociaux) sont fondues dans les quatre
  expertises ; /services redirige vers /expertises.
- Mots-clés visés : agence web Madagascar, agence web, site vitrine Madagascar, faire un site
  à Tana, comment faire un site web, Yonko Tech.
